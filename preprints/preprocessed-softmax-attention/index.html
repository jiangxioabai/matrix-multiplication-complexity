Preprocessed Softmax Attention Is as Hard as Matrix Multiplication

Tao Jiang and Minbo Gao

Co-first authors with equal contribution

First posted November 25, 2026

Read PDF BibTeX

Abstract

When softmax attention is evaluated against a fixed key–value cache, the keys and values are known before any query arrives, so the cache can be preprocessed without restriction. Existing lower bounds for attention either treat the keys and values as variable inputs or concern approximation after polynomial-time preprocessing under fine-grained hypotheses, so they do not apply to exact evaluation after unbounded preprocessing. We show that, in exact real arithmetic circuits with exponential and logarithm gates, preprocessing does not help: for almost every key matrix K∈ℝN×d and simultaneously for every nonconstant value vector, every circuit that evaluates attention on B queries, even one using arbitrary cache-dependent real constants and correct only on a small open set of queries, has size at least half the tensor rank of B×d×(N−1) matrix multiplication. Hence the generic complexity is Nω(b,a,1)±o(1) for d=Na and B=Nb, and a single query costs Θ(Nd). The proof recovers the score exponentials from derivatives of the fixed-value output and uses definable choice in the real exponential field to lift fixed-cache circuits to a smooth family, from which mixed differentiation extracts a matrix multiplication tensor. We also show that online evaluation of T queries costs Θ(TNd) even with arbitrary retained state, and that exactly B(N−1) exponential or logarithm gates are necessary and sufficient.
