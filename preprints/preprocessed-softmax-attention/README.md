# Preprocessed Softmax Attention Is as Hard as Matrix Multiplication

Tao Jiang and Minbo Gao

[Read the preprint (PDF)](./paper.pdf)

## Main result

We study exact softmax attention for a batch of queries against a fixed key–value cache. In the exact real-arithmetic circuit model with exponential and logarithm gates, we prove a matrix-multiplication lower bound for almost every key matrix and every nonconstant value vector, even after arbitrary preprocessing of the cache.
