Ridge regression

A Single Ridge Regression Prediction Is as Hard as Matrix Multiplication

Tao Jiang* and Minbo Gao*

* Equal contribution (co-first authors).

First posted November 26, 2026

Read PDF BibTeX

Abstract

The ridge regression prediction q⊤(Id+X⊤X)−1X⊤y is a single scalar, yet the standard way to compute it forms the Gram matrix X⊤X by fast rectangular matrix multiplication. We show that this is unavoidable for exact computation: for X∈ℝN×d with d=⌈Na⌉ and 0<a≤1, every arithmetic circuit computing the prediction has size Ω(Nω(a,1,a)), which matches the standard algorithm up to an No(1) factor. The lower bound is unconditional, holds even when y and q are fixed coordinate vectors, and remains true when the circuit may also use exponential and logarithm gates, a model in which earlier matrix multiplication lower bounds applied only to low-degree outputs. Our proof shows that every circuit for the prediction implicitly computes a polynomial multiple of det(Z−UV), where UV has inner dimension Θ(N), and reads the product UV off the gradient of a degeneration of this polynomial; for exponential and logarithm gates we use Ax's functional Schanuel theorem and work on a single branch of an integral algebraic function. As a consequence, a single prediction, one linear solve, matrix inversion and matrix multiplication all have the same exponent in both models.
