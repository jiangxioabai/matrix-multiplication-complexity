# A Single Ridge Regression Prediction Is as Hard as Matrix Multiplication

Tao Jiang and Minbo Gao (co-first authors, equal contribution)

[Read the preprint (PDF)](./paper.pdf) · [Full abstract](https://jiangxioabai.github.io/matrix-multiplication-complexity/preprints/exact-ridge-prediction/)

## Main result

Shows that even a single exact ridge-regression prediction has the rectangular matrix multiplication exponent, with or without exponential and logarithm gates.
