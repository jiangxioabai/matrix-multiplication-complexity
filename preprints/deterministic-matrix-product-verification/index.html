Deterministic Verification of Real Matrix Products Is as Hard as Multiplication

Tao Jiang and Minbo Gao

Co-first authors with equal contribution

First posted November 26, 2026

Read PDF BibTeX

Abstract

Given real matrices A,B,C, Freivalds' algorithm decides whether AB=C with O(N2) arithmetic operations if one-sided error is allowed, while the best deterministic method still computes AB. Whether deterministic verification over the reals can be faster than multiplication has remained open; known lower bounds apply only to restricted classes of verifiers, and over the integers quadratic-time deterministic verification is possible. We show that it cannot: every deterministic algebraic computation tree that decides AB=C for N×N real matrices has an accepting path with at least Nω/6 multiplications and divisions, so verification and multiplication have the same exponent ω; this remains true with exponential and logarithm gates, and for N×Na by Na×N products with exponent ω(1,a,1). These bounds follow from a general theorem: for every real bilinear map μ, any verifier for the graph z=μ(x,y) has an accepting path whose number of nonlinear gates is at least one sixth of the border rank of μ. The proof tilts the potential formed by the equalities on a frozen accepting path, so that its minimizers become smooth even when the tests vanish to high order on the graph, and then bounds the tensor rank of their mixed second derivatives using the Baur–Strassen theorem.
