Exact Transformer Cache Updates Are as Hard as Matrix Multiplication

Tao Jiang* and Minbo Gao*

* Equal contribution (co-first authors).

First posted November 26, 2026

Read PDF BibTeX

Abstract

Transformer inference stores the keys and values of every layer, which raises the question of how cheaply this cache can be updated exactly when an earlier token of the context is edited. We study this question for causal attention-only Transformers in a model where the context and weights may be preprocessed arbitrarily, only the edit arrives online, and the new cache is computed by a circuit with arithmetic, exponential, and logarithm gates; lower bounds for computing attention from scratch do not apply in this model. We show that for three layers, N tokens, and width d=Θ(N), changing a single scalar coordinate of the first token requires at least half the tensor rank of n×n×(d−4) matrix multiplication with n=⌊(N−1)/2⌋, so the exact update costs Nω+o(1) and is no cheaper than recomputation. The proof turns any update circuit into a bilinear algorithm for matrix multiplication by differentiating twice, first in the preprocessed data and then in the induced edge coefficients, and applies this to a cache block whose attention weights are algebraically independent along one curve. We also determine the update exponent for every fixed depth, polynomial width, and polynomial number of edits, which shows that depth three is exactly where a single edit becomes as hard as matrix multiplication.
