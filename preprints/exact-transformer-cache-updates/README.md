# Exact Transformer Cache Updates Are as Hard as Matrix Multiplication

Tao Jiang and Minbo Gao (co-first authors, equal contribution)

[Read the preprint (PDF)](./paper.pdf) · [Full abstract](https://jiangxioabai.github.io/matrix-multiplication-complexity/preprints/exact-transformer-cache-updates/)

## Main result

At width proportional to sequence length, one edit can make a three-layer attention-only Transformer cache as costly to update exactly as to recompute.
