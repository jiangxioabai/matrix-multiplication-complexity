Batched Delta Rule

The Arithmetic Complexity of Batched Delta-Rule Readouts

Tao Jiang* and Minbo Gao*

* Equal contribution (co-first authors).

First posted November 25, 2026 · Updated November 27, 2026

Read PDF BibTeX Earlier version

Abstract

In DeltaNet and related linear-recurrent models, one attention head runs the delta rule on many value channels at once. All channels share the keys, queries and gates, but each channel has its own value sequence and returns its own scalar readout at every time step. We determine how much arithmetic this batched computation needs. For sequence length N, key dimension d=N and m=Nb+o(1) value channels with fixed 0<b≤1, the optimal number of arithmetic operations for returning all Nm readouts exactly is N1−b+ω(1,b,b)±o(1), where ω(·,·,·) is the rectangular matrix multiplication exponent. With the recently stated closed formula for rectangular exponents, this exponent equals 2+b2/4. The upper bound is the chunkwise algorithm of DeltaNet with chunk length m and fast rectangular products, and it runs at depth N1−b+o(1) (and O(log2N) when b=1). The lower bound holds at every depth, even for circuits that only need to be correct for a fixed gate and unit-norm keys. The hard matrix products never appear among the outputs: they are encoded in mixed second-order coefficients of the readouts, and a bilinear-rank argument turns any circuit for the readouts into an algorithm for many independent rectangular products.
