# Work–Depth Trade-offs for Exact Delta-Rule Computation

Tao Jiang and Minbo Gao (equal contribution)

[Read the preprint (PDF)](./paper.pdf)

## Main result

We study the work needed to compute the delta-rule outputs exactly at a given circuit depth. When the state width equals the sequence length, the paper gives work bounds at polynomial and polylogarithmic depths conditional on claimed square and rectangular matrix multiplication exponents. It also gives an unconditional reduction from dense triangular substitution to the delta rule.
