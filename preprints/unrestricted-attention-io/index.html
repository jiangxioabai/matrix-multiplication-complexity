Memory I/O

On the Unrestricted I/O Complexity of Exact Softmax Attention

Tao Jiang and Minbo Gao

Co-first authors with equal contribution

Read PDF BibTeX

Abstract

The I/O complexity of attention counts the words that an algorithm moves between a fast memory of size M and a slow memory. Known lower bounds for exact attention either fix the computation graph or assume that the algorithm computes the entries of QK⊤, and below the memory threshold M=d2 they do not determine whether fast matrix multiplication, or an algorithm that never forms the attention scores, can communicate less. We study straight-line algorithms that may perform unlimited arithmetic, exponentials, logarithms and recomputation, and show that for N queries and keys of width d=N and memory M=O(N2), exact softmax attention requires Ω(N2+N9/4/M1/8) transfers, even with a single scalar value per key. A blocked algorithm built on the exponents of a recent preprint, which determines the matrix multiplication exponent to be 9/4, matches this bound up to No(1) factors, so the I/O exponent equals 9/4−μ/8 when M=Θ(Nμ). The lower bound combines an I/O-efficient reverse-mode differentiation lemma, which extracts a matrix product from the gradient of one attention channel, with a tensor inequality, derived from the spectral theory of that preprint, that limits how many tensors of bounded local dimension can sum to a matrix multiplication tensor. For width d=Na with a<1, we give upper and lower bounds on the I/O exponent that coincide at constant memory and at the input-size endpoint.
