# The Arithmetic Complexity of Exact Polynomial Attention

Tao Jiang and Minbo Gao (equal contribution)

[Read the preprint (PDF)](./paper.pdf)

## Main result

We study normalized polynomial attention in extended arithmetic circuits. For every fixed even degree, we reduce exact evaluation to the algebraic complexity of the unnormalized numerator with constant overhead. With N queries and keys of width N^a, the exact quadratic-attention exponent is ω(1, a, a), the exponent for multiplying an N × N^a matrix by an N^a × N^a matrix. At higher even degrees, polynomial selectors embed a direct sum of rectangular matrix products into one attention computation, yielding degree-dependent lower bounds.
